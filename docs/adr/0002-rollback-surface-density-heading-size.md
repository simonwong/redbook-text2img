# 回滚内容底板配置、三档密度与正文标题大小

ADR 0001 落地后（#14–#21）的实际使用暴露了过设计：内容底板（无底板/浮层卡/备忘录）作为用户配置理解成本高、备忘录底板观感差；三档密度不够用；正文标题大小与密度职责重叠。本决策把这些能力回滚到更合适的形态，三层模型本身保留。

## Decision

- 样式配置不再包含内容底板。浮层卡与备忘录装饰顶栏降级为主题内部元数据（PresetTheme.internals），用户不可配置；备忘录底板（横线信纸）整体删除，Apple 备忘录主题回到纯色画布加装饰顶栏。
- 密度恢复五档（紧凑/较紧/正常/较松/宽松），沿用旧五档 token 取值。旧三档持久化值按像素等价迁移（balanced→normal；compact/spacious 名称与五档恒等，保证界面可选且刷新稳定）。
- 样式配置不再包含正文标题大小；正文标题字号只由密度经标题倍率推导。
- 画布背景在"内置方案或纯色"之外恢复封闭渐变与封闭图案集合（本地 SVG data-URI），仍然禁止任意 CSS 与远程资源。
- 所有被移除字段的持久化旧值由 hydrate 白名单静默丢弃，不提升 persist 版本号。

## Considered Options

- 保留三档密度并按版本号区分迁移路径：拒绝。sanitize 被 hydrate 与界面 patch 共享，compact→snug 式重映射会让新档位在界面不可达；名称恒等是唯一自洽的方案。
- 保留内容底板但换掉备忘录底板：拒绝。用户明确不需要该配置维度；主题内部元数据已足够表达浮层卡与顶栏。
- 开放任意渐变/图片背景：拒绝。与 ADR 0001 一致，封闭集合保证导出安全与可读性。

## Consequences

- 新增主题级视觉细节（如新的装饰元素）应优先作为 PresetTheme.internals 的封闭元数据，而不是恢复用户配置字段。
- 旧版设置过 compact/spacious 覆盖的用户刷新后偏移一档（15→14px / 17.5→19px）；主题默认值不受影响。
- ADR 0001 中"内容底板三值封闭集合""密度三档""背景只允许受控方案或纯色"三点由本 ADR 取代，其余决策继续有效。
