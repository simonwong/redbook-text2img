# 卡片边框与比例、强调色、图片磨砂、系统字体扩充、自定义主题与扁平设置面板

三层主题系统（ADR 0001）上线后，样式配置只剩背景、密度、字体、正文标题对齐、封面版式五个维度，用户反馈"能改的太少"：想要导出图自带一圈白边、想换比例、上传的照片当背景时文字不易读、加粗和标题没有颜色可调、调好的配置没法保存复用。设置面板六组小标题在紧凑化之后也显得比内容还重。本决策一次性扩充样式配置并重排设置面板，全部在现有 Style System Module 内实现，不新增 Seam。

## Decision

### 卡片边框

- 样式配置新增 `cardFrame`，封闭集合 `none | white`。`white` 为 3px 不透明白色内边距，外圆角 16px，内圆角 13px，是导出节点的一部分，导出图自带白边。
- 预览中卡片外框只画阴影与 1px 极淡描边，不再在导出节点之外叠装饰白边，避免"双边"。
- 8 个内置主题默认 `none`，现有导出图不变；用户可覆盖。

### 卡片比例

- 样式配置新增 `aspectRatio`，封闭集合 `3:4 | 1:1 | 9:16`。卡片逻辑宽度固定 375px，高度由比例决定（500 / 375 / 667）。封面与正文共用比例。
- 不提供 4:3 等横向比例：小红书会裁切横图。
- 渲染样式新增卡片尺寸；预览、溢出判定、缩放和导出都从渲染样式读取尺寸，不再写死。内置主题默认 `3:4`。

### 图片背景磨砂

- 图片背景（`kind: "image"`）新增 `frost` 字段，封闭集合 `none | light | medium | strong`，默认 `none`。纯色、渐变、主题背景不提供磨砂，无内容可模糊。
- 磨砂由样式基础实现为两层：模糊的图片层（CSS `filter: blur()` 加轻微放大遮住边缘发白）与半透明纯色蒙层（按图片明暗基调选白或黑）。三档分别对应模糊半径与蒙层透明度的固定组合，用户不接触数值。
- 采用 `filter` 而非 `backdrop-filter`：html2canvas-pro 2.4 将 `filter` 直接映射到 Canvas 2D `ctx.filter`，`backdrop-filter` 则完全不被解析。e2e 必须比对预览与导出的模糊一致性；若某浏览器的 `ctx.filter` 不可用，回退到上传时离屏预生成模糊图，此回退在本 ADR 内视为实现细节，不改变配置语义。

### 系统字体扩充

- 字体集合从 `sans | serif` 扩为 `sans | serif | kai | mono`，全部为系统字体栈，不加载 Web 字体。
- 不加圆体：Windows 无系统圆体，会静默退回无衬线，两端所见不一致。
- CONTEXT.md 排版条目的"避免"列表同步修改。

### 强调色

- 样式配置新增 `accentColor`，6 位十六进制值。它作用于正文标题（h1–h3）、加粗、列表标记、引用左边线与链接；正文段落颜色仍由样式基础按背景明暗自动派生，不开放。
- 样式基础对强调色做对比度保障：与当前背景基调对比不足 4.5:1 时，沿明度方向调整到达标为止；用户看到的色板与实际渲染色可能略有差异，这是刻意的。
- 每个内置主题声明自己的强调色（取自当前派生值，视觉不变），用户可覆盖；界面提供 8 色封闭色板加自定义取色器。
- 这与 ADR 0003 移除的"装饰颜色"语义不同：装饰颜色只服务标题装饰，强调色是 Markdown 语义色的统一入口。ADR 0001 中"装饰颜色不得覆盖 Markdown 高亮、链接、列表或引用颜色"一条随之作废。

### 自定义主题

- ADR 0001 预留的"自定义配置"本期交付，术语定为**自定义主题**：用户命名保存的完整样式配置，与内置主题并列出现在主题网格中，可选择、可删除、可用当前配置覆盖更新。
- Style System 状态新增 `customThemes` 列表，随现有持久化一起保存；目录接口按状态返回内置与自定义主题，条目带来源标识。命令新增保存、覆盖更新、删除；保存后当前主题切换为新主题且覆盖清空；删除当前自定义主题时回落到默认内置主题。
- 上限 8 个。图片背景的 data URL 会随主题一起存入 localStorage，超出配额时保存失败并提示，不引入 IndexedDB。
- 有覆盖时设置面板底部出现"另存为主题"入口；当前为自定义主题时额外提供"更新此主题"。
- 卡片标记（署名、页码）不属于样式配置，不随自定义主题保存。

### 扁平设置面板

- 设置面板从 ADR 0001 的六组标题结构改为扁平字段行：只保留"主题"一个标题行（承载恢复主题配置入口），其余字段各占一行，行首为小号标签（背景 / 比例 / 边框 / 密度 / 字体 / 标题对齐 / 封面版式 / 强调色），修改标记与单项恢复挂在行标签上。
- 卡片标记不设标题：署名输入框用占位文字表意，页码为带文字的开关。
- 分组语义以 sr-only 标签保留给辅助技术。ADR 0001"固定显示六组"与 ADR 0004"保留六组固定结构"两条由本条取代。

### 状态容器收敛

- 状态容器只暴露一个 `updateConfiguration(patch)` 加既有的选择、恢复、撤销与自定义主题命令；按字段命名的五个 setter 删除。规则不变，只是 Interface 变小。

## Considered Options

- 开放正文文字色与单独的标题色：拒绝。会打破样式基础对自定义背景的自动可读性保障，用户换背景后需要手动调色。
- 磨砂对全部背景种类开放：拒绝。纯色与渐变无可模糊内容，开关只会制造困惑。
- 用 `backdrop-filter` 做磨砂：拒绝。导出链路完全不支持。
- 加载子集化 Web 字体扩充字体：拒绝。中文字体体积大，用户明确只要系统字体。
- 自定义主题存 IndexedDB：拒绝。与 ADR 0004 一致，配额问题用上限与失败提示解决。
- 保留全部分组标题：拒绝。新设计的控件形态已能自解释，标题比内容更重。

## Consequences

- 样式配置从 5 个字段增至 8 个（含 `frost` 作为图片背景子字段）；旧持久化值缺失的字段由 hydrate 补默认值，不提升 persist 版本号。
- 自定义主题的配置是完整快照；本 ADR 之后再新增配置字段，必须为已保存的自定义主题补默认值。
- 导出节点结构增加边框层和磨砂两层，`docs/html2canvas-pitfalls.md` 新增 `filter` 与 `backdrop-filter` 条目。
- 主题缩略图需要从任意样式配置生成，以支持自定义主题预览。
- GitHub issue #12（强调样式在哪里改）由强调色回应；#6（背景太少）由 ADR 0004 与本 ADR 的磨砂共同回应。
