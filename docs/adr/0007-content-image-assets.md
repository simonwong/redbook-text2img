# 内容图片入库引用与导出一致性

内容图片先导入本地资产库，再通过 `![说明](image:a1b2c3d4e5)` 引用。资产 id 由两个存储实现共用的生成函数通过 `crypto.getRandomValues` 生成，为 10 位 base36 小写字母数字。默认 `align=center` 与 `size=full` 不写入查询串；非默认配置如 `![说明](image:a1b2c3d4e5?align=left&size=s)`。解析仍兼容旧 id 与显式默认参数。Markdown 只保存短引用；图片不占用草稿和主题的 localStorage 配额。复制 Markdown 到其他浏览器或设备不会携带图片资产。

资产库用 IndexedDB 保存 Blob，存入、读取、列出、删除共用一个接口，内存实现用于测试和存储不可用时的会话回退。导入时 IndexedDB 打开或写入失败才回退到内存并提示图片仅在本次会话保留；读取失败只通知占位，不写入永久缺失快照，下次加载可重试。上传先通过 img 与 object URL 读取自然尺寸，再用 createImageBitmap 的 resize 选项按最长边 2000 等比解码；空 MIME 类型交给解码校验。像素含透明度时输出 PNG，否则输出 JPEG。内容变更不删除资产，避免撤销后丢图。

禁止纯远程图片引用：html2canvas-pro 在跨域图片没有 CORS 许可时可能静默缺图，预览成功不能证明导出成功。未导入的图片显示说明占位；缺失资产也显示含 alt 的占位，并随卡片导出。

预览不做 SSR：`src/features/layouts/index.tsx` 在 `isHydrated` 为 false 时返回 null，预览仅在浏览器挂载。资产加载结果保存在模块级同步缓存，组件通过 `useSyncExternalStore` 订阅；object URL 在会话期间不撤销。缓存避免切页重新异步取图，且不使用 Suspense，以免导出截到 fallback。若将来启用预览 SSR，必须重新设计资产解析与 hydration 边界。

仅含一张图片的 Markdown 段落通过 react-markdown 提供的 node 判定，渲染为全宽 figure，不在 p 中嵌套块级容器。figure 负责居中；img 宽高均为 auto，同时受 max-width 和按卡片高度一半生成的像素 max-height 约束。正文和封面内的内容图片共用这些规则。

导出模块在单张和批量绘制前等待资产占位完成更新，再等待节点内所有 img.decode()；加载超时或解码失败则终止该次导出，单张与批量均以 role=alert 显示可读原因。html2canvas-pro 等待图片像素不等于等待预览布局。溢出检测监听内容中的图片 load 和节点变化，在异步加载与占位替换后重新测量。


## 图片导入入口与远程代理

本地文件选择、粘贴和拖拽共用入库与插入流程；图片文件由 CodeMirror DOM 事件处理器拦截，非图片文件保持默认行为。拖拽使用落点位置，异步入库期间通过文档变更映射维护插入范围，多张图片用 Promise.allSettled 并发导入，成功项在一次事务中插入，撤销一步恢复；失败项按文件名逐项提示。上传、粘贴、拖拽与会话回退共用堆叠横幅，可关闭，6 秒自动消失，弹层关闭不移除提示。

远程链接由浏览器使用 CORS 与 no-referrer 直连抓取，失败统一回落 Node Route Handler；不根据浏览器异常猜测 CORS、404 或离线。代理在存在 Sec-Fetch-Site 时仅接受 same-origin 或 none；缺少该头时优先比较 Origin，否则比较 Referer 与请求 URL 的 origin，缺失或不匹配返回 FORBIDDEN_ORIGIN（403）。仅允许空、80、443 端口，不转发 Referer、Cookie 或认证头。每跳都校验 URL、解析全部 DNS 地址并拒绝受限网段，再用 Node http/https 的 lookup 固定已校验地址，最多跟随三次重定向。直连与代理共用同构魔数校验，直连读取 Blob 前 16 字节，显式拒绝 SVG；只接收 image/* 且通过 PNG、JPEG、GIF、WebP、AVIF 或 BMP 魔数检查的响应；原始图片字节流上限 4MiB，DNS、重定向、响应头和响应体共用 10 秒总期限。

代理以 NDJSON 流封装图片字节块与最终完成或错误消息，不积累整张图片后再返回。原因是 HTTP 头发出后无法把超限或超时改为 413/504；流内错误码让用户仍能得到准确原因。头发出前的错误使用 HTTP 状态码与同样的错误码，浏览器只在收到完成标记后构造 Blob 并入库，截断流与错误流均不插入引用。传输层 Content-Type 为 application/x-ndjson，image/* 限制作用于上游响应，图片的实际类型以魔数为准。

## 内容图片样式配置

内容图片的圆角（无、小、大）与阴影（无、轻、重）属于完整样式配置，随内置主题、自定义主题、切换与重置生效。旧数据由 hydrate 补当前主题默认值，不提升持久化版本。设置面板末尾使用带可见标题“图片设置”的独立区块；根据 imageReference.ids(content).length > 0 显示圆角与阴影两行，未导入外链不触发样式行，隐藏时仍保留配置，避免删除图片再撤销后丢失外观。

调整层（adjustments.ts）按画布明暗派生阴影颜色，圆角与阴影经同一 resolve 出口写入 img 渲染样式，正文与封面共用，预览与导出保持一致。主题缩略图不展示这两项。

## 逐图尺寸与对齐

图片引用的 align 与 size 由渲染样式出口解析为容器样式，正文与封面共用。figure 保持全宽并用 justify-content 对齐，内部图片容器按小、中、大、通栏取内容区宽度的 40%、60%、80%、100%。内部容器同向对齐自然尺寸较小或受高度上限约束的图片；img 保持 auto 宽高与原有最大宽高约束。

编辑器在当前行仅含一条本地资产图片引用时显示对齐与尺寸选项，复用分段控件，窄屏横向滚动。稳定的 CodeMirror 扩展在切换明暗主题后仍同步光标行上下文；文档变更照常更新行文本，预览页码仅响应没有 ExternalChange 注解的用户 select、input、delete 事务，首次读取和外部正文替换不改变手动选择的预览页。每次点击只改写当前行图片地址，保留说明、标题与空白；默认参数省略，每次修改独立为一个可撤销事务。

## 图片页与配图封面

分页段落去掉空行后仅剩一条内容图片引用时标记为图片页，标题显示“图片页”。引用由 imageReference 的 Markdown 解析出口判定；混排、多图、代码和未导入外链不进入图片页。封面判定与标题提取通过同一 Markdown 解析出口跳过开头的单图片行（含未导入外链）和空行，再检查首个正文行是否为一级标题。

图片页复用现有卡片 container/frame，跳过正文内边距、装饰顶栏与裁切线；图片以 object-fit: cover、居中位置铺满卡片。选择满版照片的连续画面，接受原图边缘被裁切，不保证完整显示；卡片比例、圆角和白边照常。图片页使用独立渲染样式，styleSystem.resolve 在 page 为 image 时不返回 frost，组件只消费结果；内容图片圆角、阴影与逐图尺寸、对齐均不生效。卡片标记绝对定位在底部，以白字和淡黑色 text-shadow 叠在图片上，署名与正文页码规则不变。图片加载、缺失占位与导出前 decode 等待复用现有资产链路。非 ready 占位保留 innerContainer 内边距；ready 图片跳过内边距。

## 远程占位导入与显式清理

http/https 图片地址仍由预览 URL 过滤清空，原地址只作为占位操作的数据传给组件，不写入 img.src。点击导入先按 normalizeUri 归一化后的 URL 定位第一条匹配的行内图片，定位失败时不抓取、不入库；成功后复用 fetchRemoteImage 与资产入库，再读取 Markdown content store 的最新全文重新定位并只改写地址；保留说明、标题与其他正文，跳过代码和普通链接。定位来自全文重新解析，不使用预览切片的 node.position；改写后回读 Markdown，仅在同位置仍为 image、URL 为目标地址且 alt/title 未变时接受，否则保留原文。重复 URL 每次只导入第一条；导入期间引用被移除时不恢复旧正文，显示无法改写的原因，已入库资产留待显式清理。

占位文字保留在导出节点中；按钮及导入错误操作区标记 data-export-ignore，html2canvas-pro 的 onclone 仅移除克隆节点中的操作区。原预览仍可交互，导出包含说明与缺失状态，不包含操作按钮。

“图片设置”区块位于卡片标记与自定义主题操作之后，统一管理图片相关设置：正文有本地资产引用或资产库非空时显示；圆角与阴影仅在正文有本地资产引用时显示，“清理未使用图片”作为标题右侧的 ghost、sm 操作，仅在资产库非空时显示；确认与结果提示保留在区块正文中。最后一条引用删除后保留清理入口，正文无图且库为空时，分组保留清理结果（含部分失败），用户点击“知道了”关闭提示后整组消失。分组挂载时列出资产，并订阅会话变更重新读取；读取失败按空库处理，卸载时取消订阅并丢弃在途结果。会话接口列出持久化与内存资产的并集，按 imageReference.ids(最新正文) 计算差集。用户查看数量与“多标签页只以当前内容为准”提示后确认，逐个删除；每次删除前复核当前正文，跳过已恢复的引用。删除成功同步清除 ready 快照并通知预览显示缺失，object URL 保持原有会话期生命周期，避免打断在途导出。部分删除失败报告实际已清理数量，不报告全部成功。

删除引用、切模板、重置内容与启动均不自动回收资产；恢复引用仍能读取图片。清理仅依据当前标签页正文，不能保护其他标签页独有内容，确认提示说明清理无法恢复。
