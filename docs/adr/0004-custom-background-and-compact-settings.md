# 背景配置收敛为自定义纯色/渐变/本地图片，设置面板紧凑化

ADR 0002 恢复的封闭渐变/图案集合实际使用率低且把设置面板撑得过长；用户需要的是少量高价值自定义（纯色、渐变、自己的图片），而不是在十几个内置方案里挑选。本决策收敛背景配置并整体紧凑化设置面板。

## Decision

- 背景选择收敛为四项：主题背景（当前主题自带背景，选中即清除覆盖）、纯色（取色器）、自定义渐变（双色 + 上下/左右/对角封闭方向）、本地图片（上传压缩为 JPEG data URL，≤1600px，超约 3MB 拒绝，仅存 localStorage）。禁止远程资源与任意 CSS 的规则不变。
- 模型层删除 `gradient`/`pattern` 背景种类与封闭预设集合；旧持久化值由 hydrate 白名单静默丢弃，回落主题背景，不提升 persist 版本号。
- 自定义渐变的明暗基调取两端颜色的平均亮度；图片基调在上传时对缩样像素采样。两者据此自动套用可读语义色，与纯色一致。
- 字体去掉「跟随主题」选项：未覆盖时直接回显当前主题字体；选择与主题默认值相同的字体时不产生覆盖（diff 自动清除）。
- 主题选中态从「当前/已调整」文字徽标改为右上角勾选角标，文字状态保留为 sr-only 供辅助技术读取。
- 设置面板保留 ADR 0001 的六组固定结构（分组标题承担作用域表达），仅压缩行距与字段行高；背景组的字段级标签移除，修改标记与单项恢复提升到分组标题行。

## Considered Options

- 保留封闭渐变/图案集合作为额外分组：拒绝。与用户自定义能力重叠，面板长度是本次主要投诉。
- 自定义渐变开放色标数量与任意角度：拒绝。双色 + 三方向已覆盖绝大多数需求，且保持「无透明色标」的导出安全约束（docs/html2canvas-pitfalls.md 第 6 条）。
- 图片背景存 IndexedDB 而非 localStorage：拒绝。压缩后体积约百 KB，与现有 persist 链路一致即可；IndexedDB 引入第二套持久化语义，得不偿失。
- 去掉全部分组标题：拒绝。ADR 0001 要求设置结构表达控制对象与影响范围，六组标题是扫描长面板的主要锚点；紧凑化通过间距收敛而非删除结构实现。

## Consequences

- 背景覆盖的 diff/等值比较对图片按 dataUrl 全字符串比较；`applyCanvasConfiguration` 改为直接比对解析后的背景样式值以保持幂等，不再反查背景标识。
- 旧版设置过受控渐变/图案背景的用户刷新后回到主题背景，需重新选择。
- ADR 0002 中「背景恢复封闭渐变与封闭图案集合」的决策由本 ADR 取代；「禁止任意 CSS、远程资源」继续有效。
